Set aside: typed in the list, like a form

One sheet, one line per account, no boxes and no second lines. Each row's right side is its amount field (like "Amount" in Add transaction): empty rows show what is free in light grey, as a hint. Tap a row: cursor goes there, the number pad comes up, and the bar above the number pad shows what is free, tap it to fill. Save is blocked while any amount is more than is free. Invented figures; goal "Hajj 2030", Rp 43.260.000 still needed.
