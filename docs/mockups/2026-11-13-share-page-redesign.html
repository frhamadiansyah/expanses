The flow

AShare page
  ├─ Members · Shared with Andi · Sync row (a red count when something needs fixing) → BSync details → Technical log (the text "Details" shows today) · Copy for support
  ├─ Members: own row → rename · Invite someone → invite code
  ├─ Shared with Andi → Cone list: "Always shared" box · accounts & cards · goals · events · assets & debts
  │     └─ an event's switch → Dshare sheet with its code (on) / Leave confirm (off)
  └─ Stop sharing Family (Rina) / Leave Family (Andi) — last, alone
