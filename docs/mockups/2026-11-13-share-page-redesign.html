The flow

AShare page
  ├─ status line under the title (Up to date / Syncing / ⚠) → BSync details → Technical log (the text "Details" shows today) · Copy for support
  ├─ orange box (only when something needs action) → the page that fixes it
  ├─ Members: own row → rename · Invite someone → invite code
  ├─ Shared with Andi → Cone list: accounts & cards · goals · events · assets & debts
  │     └─ an event's switch → Dshare sheet with its code (on) / Leave confirm (off)
  ├─ Sync details (also a row, for whoever looks for it)
  └─ Stop sharing Family (Rina) / Leave Family (Andi) — last, alone
