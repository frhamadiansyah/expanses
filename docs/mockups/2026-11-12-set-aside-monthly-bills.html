Set aside for monthly bills

Today only bills that are not monthly can save up (Sinking fund). Proposed: a monthly bill can keep its next payment set aside in a bank account, so that money shows as “Set aside”, not “Free to spend”, until the bill is paid. Nothing moves between accounts; it is a promise on the balance, the same as a goal’s Money set aside. Names and amounts are made up.
