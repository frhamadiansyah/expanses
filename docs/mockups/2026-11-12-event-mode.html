Event mode: new transactions go to the event by themselves

Turned on from an event. While it is on, every transaction added (by hand, One line, a captured SMS or email) is tagged with the event, and the Add form opens in the event’s currency. It turns itself off the day after the event ends. One event at a time. Names and amounts are made up.
