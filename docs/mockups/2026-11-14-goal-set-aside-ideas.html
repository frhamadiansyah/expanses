Set aside: four other ideas

The problem: on tapping Set aside it is not clear how much can be used. Each idea below puts that number first, in a different way. Same invented goal: "Hajj 2030", target Rp 120.000.000, Rp 43.260.000 still needed. Mandiri Tabungan has Rp 20.000.000, of which Rp 13.500.000 is already set aside for other goals, so Rp 6.500.000 is free.

A · One account at a time Recommended

Set aside opens a plain list: each account with its free money on the right, nothing to type. Tap one and a single amount screen opens, like typing a transaction: the free amount is right above the number, and two buttons fill it. Changing an amount later = tap that account in Funded by, same screen, with "Remove" at the bottom.
