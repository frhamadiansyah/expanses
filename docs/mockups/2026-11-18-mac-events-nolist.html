Mac Events · without the left list

Owner: the left list wastes space with only one or two events. Two ways that use the full width. The event's own page (boxes, Transactions / Plan table, side peek) stays as in the first mockup.

A · An Events page of cards, then the event full width

Events opens on cards, a few per row (Now and next, then Past), each with dates, spent and plan bar. With one or two events it is just one short row, no empty column. Click a card: the event fills the page. The title is a menu (⌄) to jump to another event without going back; "‹ Events" returns to the cards.
