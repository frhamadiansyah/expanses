4 · Trip: a small plane on the icon, no trip name on the grey line

A trip's spending is not in Cashflow normally. It shows only (a) on an account's own page (its history keeps everything), (b) in a workspace with Settings → Budget → "Events count in the budget" on, and (c) on the trip's own page. In those places the row gets a small grey plane on its icon, like the refund arrow. If a row is both a refund and on a trip, the refund arrow wins (the plane is still on the receipt).

12 · Deleted rows

On the phone they never show. "Show deleted" is a filter only on a wide screen (Mac/iPad), where a deleted row reads struck through. Delete keeps a hidden marker so the other phone deletes it too and Undo works; it is never counted anywhere. The filter can be removed if it isn't wanted.
