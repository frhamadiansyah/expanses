What is off

Marked with dashed red on the left.

  • Back says "Events" and goes to the list; the page came from the event.
  • Name, Dates, Categories, Currency look like separate rows but all open one form that replaces them.
  • The edit form has a different order (Categories before Currency before dates) and a bold Currency.
  • Save and Cancel are two extra boxes.
  • Done is a switch, though it is something done once (and moves the event to Past).
  • No headers: nothing says which group is what.

After Proposed

One page, no edit mode: each row is changed where it is and saved at once. Grouped: what the event is, how it counts money, what it shows, who sees it, then finishing and deleting. Same order and look as the shared trip's Settings.
